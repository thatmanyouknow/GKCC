GKCC v0.4.2 GITHUB UPDATE STEPS
================================

IMPORTANT: Do not upload this ZIP as one file and stop there. GitHub will store
it as a ZIP; it will not unpack it into the repository, and Moonraker cannot
update the application that way.

1. Extract GKCC_GitHub_Upload_v0.4.2.zip on your Windows PC.
2. Open the extracted "GKCC-upload" folder.
3. Open https://github.com/thatmanyouknow/GKCC in your browser.
4. Click Add file -> Upload files.
5. Drag ALL CONTENTS from inside GKCC-upload into the upload page.
   README.md, install.sh, calibration_center.py, index.html, and the JSON guide
   files must appear at the root of the repository. Do not leave them inside
   another folder.
6. Use this commit message:
       Add highlighted cfg editing window v0.4.2
7. Commit directly to the main branch.
8. On the Releases or Tags page, create tag:
       v0.4.2

UPDATE THE PRINTER
==================

In Mainsail, open Update Manager and press Update beside gkcc.

If this is the first installation instead:

cd ~
git clone https://github.com/thatmanyouknow/GKCC.git
cd GKCC
sudo bash install.sh

Open:
http://mainsailos.local:7128

WHAT v0.4.2 ADDS
================

- Keep the relevant live/imported .cfg file open beside the guided form.
- Highlight the exact section and option being edited with line numbers.
- Show current loaded value versus the draft value while typing.
- Mark newly inserted settings and automatically scroll them into view.
- Open a larger configuration-file window from any guided field.
- Open Blobifier servo and bucket pins directly in blobifier_hw.cfg.
- Preserve the v0.4.1 Blobifier commissioning workflow and v0.3 transactional backup/apply/rollback protections.

LIVE-APPLY FIRST USE
====================

1. Open Configuration builder -> Start / import.
2. Unlock controls.
3. Press Load/rebase live files.
4. Make or review the guided changes.
5. Open Review / export, then Live apply.
6. Press Preview changed files and inspect every diff.
7. Type APPLY and press Back up and apply live.

The backup protects file recovery. It does not prove that electrical pins,
thermistors, currents, heater limits, or movement values are safe.

- Dedicated Blobifier setup, geometry, dry-run, test-blob, tuning, backup, and live-apply workflow.
