GKCC v0.5.2 PROTECTED-PATH SAFETY UPDATE
==========================================

Upload ALL CONTENTS from inside GKCC-upload directly into the repository root.
Do not upload the ZIP as a single repository file.

1. Extract GKCC_GitHub_Upload_v0.5.2.zip on Windows.
2. Open the extracted GKCC-upload folder.
3. Open https://github.com/thatmanyouknow/GKCC and select the main branch.
4. Click Add file -> Upload files.
5. Press Ctrl+A inside GKCC-upload and drag every selected item to GitHub.
6. Confirm these files appear at the repository root before committing:
     VERSION
     release_manifest.json
     calibration_center.py
     index.html
     config_builder.json
     ellis_guide.json
     erfc_guide.json
     blobifier_guide.json
     workflows.json
     config.default.json
     install.sh
     SHA256SUMS
7. Commit directly to main with:
     Protect updater-managed cfg files and improve rollback v0.5.2
8. GitHub's web uploader cannot delete old tracked files. On the repository Code
   page, delete the obsolete root item named "download" if it is still present.
   Also delete a tracked __pycache__ folder if GitHub shows one. Commit that
   cleanup to main before creating the v0.5.2 release/tag.
9. Create/publish the GitHub release tag v0.5.2 targeting main.
10. In Mainsail Update Manager, update gkcc.
11. Restart the gkcc service if Update Manager does not do it automatically.
12. Refresh the browser with Ctrl+F5.
13. Open Installation health. Every critical component should show OK before
    using Live apply or restoring a configuration backup.
14. Open Configuration builder and choose Reload live clean once. This clears
    stale draft cfg edits from the failed v0.5.0 transaction while preserving
    workflow progress, notes, and taught positions.
15. Preview changed files. Happy Hare core symlinks should appear read-only if
    a draft still attempts to change them, and Apply must remain blocked.

If Installation health reports a mismatch, do not use Live apply. The page will
identify the exact missing, corrupt, or wrong-version file.
