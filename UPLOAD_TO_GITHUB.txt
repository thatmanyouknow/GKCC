GKCC v0.5.0 CLEAN CONSOLIDATION UPDATE
======================================

This release repairs the mixed filenames that caused the browser flatMap error.
Upload ALL CONTENTS from inside GKCC-upload directly into the repository root.
Do not upload the ZIP as a single repository file.

1. Extract GKCC_GitHub_Upload_v0.5.0.zip on Windows.
2. Open the extracted GKCC-upload folder.
3. Open https://github.com/thatmanyouknow/GKCC and select the main branch.
4. Click Add file -> Upload files.
5. Press Ctrl+A inside GKCC-upload and drag every selected item to GitHub.
6. Confirm these files appear at the repository root before committing:
     VERSION
     release_manifest.json
     calibration_center.py
     index.html
     config_builder.json
     ellis_guide.json
     erfc_guide.json
     blobifier_guide.json
     workflows.json
     config.default.json
     install.sh
     SHA256SUMS
7. Commit directly to main with:
     Consolidate and repair GKCC v0.5.0
8. On the repository Code page, delete the obsolete tracked item named "download"
   if it is still present. Also delete a tracked __pycache__ folder if GitHub shows it.
9. In Mainsail Update Manager, update gkcc.
10. Restart the gkcc service if Update Manager does not do it automatically.
11. Refresh the browser with Ctrl+F5.
12. Open Installation health. Every critical component should show OK before
    using Live apply or restoring a configuration backup.

If Installation health reports a mismatch, do not use Live apply. The page will
identify the exact missing, corrupt, or wrong-version file.
