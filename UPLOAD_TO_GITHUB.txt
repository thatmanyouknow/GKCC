GKCC v0.4.5 GITHUB UPDATE STEPS
================================

IMPORTANT: Do not upload this ZIP as one file and stop there. GitHub will store
it as a ZIP; it will not unpack it into the repository, and Moonraker cannot
update the application that way.

1. Extract GKCC_GitHub_Upload_v0.4.5.zip on your Windows PC.
2. Open the extracted "GKCC-upload" folder.
3. Open https://github.com/thatmanyouknow/GKCC in your browser.
4. Click Add file -> Upload files.
5. Drag ALL CONTENTS from inside GKCC-upload into the upload page.
   README.md, install.sh, calibration_center.py, index.html, and the JSON guide
   files must appear at the root of the repository. Do not leave them inside
   another folder.
6. Use this commit message:
       Fix Happy Hare parameter population v0.4.5
7. Commit directly to the main branch.
8. On the Releases or Tags page, create tag:
       v0.4.5

UPDATE THE PRINTER
==================

In Mainsail, open Update Manager and press Update beside gkcc. Then refresh the
GKCC page with Ctrl+F5.

After the update:

1. Unlock GKCC.
2. Open Configuration builder -> Start / import.
3. Press Load/rebase live files again.
4. Return to Happy Hare geometry and operating parameters.
5. Existing values from the [mmu] section should populate and Open in cfg should
   highlight the existing option instead of adding [mmu_parameters].

WHAT v0.4.5 FIXES
=================

- Reads Happy Hare parameters from the real [mmu] section.
- Migrates older GKCC draft values from the incorrect [mmu_parameters] section.
- Routes [mmu] edits and exports to mmu/base/mmu_parameters.cfg.
- Prevents calibrated_bowden_length from being added as an invalid [mmu] option.
- Preserves the backed-up diff/review/live-apply workflow.
